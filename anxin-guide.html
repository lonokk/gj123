四、突發狀況處理 SOP 包含疾病不適、天然災害、失聯、送餐未取處置流程
✚
💡 核心應變原則：邊處理、邊回報[cite: 9]
突發事件處理期間，請務必於平台聊天室「優先處理管理」按下 【開案】（訊息將反紅置頂警示全員）[cite: 9]；處置完全結束後按下 【解除】 恢復常態[cite: 9]。
🩺 疾病或身體不適[cite: 9]
1. 狀況評估：確認是否有生命危險或屬緊急狀況[cite: 9]。
2. 應變處置：
• 緊急/危險：撥打 119 送醫陪同 ➔ 平台回報個案狀況 ➔ 按【開案】置頂[cite: 9]。
• 非緊急/難判斷：平台回報狀況 ➔ 按【開案】置頂 ➔ 醫護/個管師給予建議[cite: 9]。
3. 醫療處置：優先解決個案健康問題[cite: 9]。
4. 後續妥處：住院期間通報狀況 ➔ 共同評估後續處遇（返家/護理之家/榮家/長照機構） ➔ 按【解除】[cite: 9]。
🌊 天然災害 / 突發事件[cite: 9]
1. 確認安全：先確保自身安全，再確認服務對象安全[cite: 9]。
2. 救援處置：
• 安全：群組回覆並持續追蹤[cite: 9]。
• 危難/風險：通報警消救難單位 ➔ 平台【開案】置頂 ➔ 評估需求並連結社區資源[cite: 9]。
3. 緊急安置：有必要時於平台協調社政、榮家或長照機構緊急安置[cite: 9]。
4. 結案恢復：風險排除後於平台按【解除】[cite: 9]。
🔍 失聯協尋[cite: 9]
1. 查證失聯：詢問親友/鄰居/長照單位最後接觸時間[cite: 9]。暫時外出則群組追蹤；確認失聯則啟動協尋[cite: 9]。
2. 啟動協尋：平台按【開案】置頂 ➔ 協請相關人員共同尋找[cite: 9]。
3. 報案協處：最遲 24 小時未尋獲，向警政單位報案[cite: 9]（有眷通知家屬，單身由榮服處辦理）[cite: 9]。
4. 尋獲妥處：確認健康（必要時通報 119 送醫） ➔ 平台回報處置 ➔ 按【解除】[cite: 9]。
🏠 送餐未取 / 多時未外出[cite: 9]
1. 生活跡象確認：檢查交通工具、門鎖狀態（外鎖/反鎖），聯絡親友鄰居釐清[cite: 9]。
2. 評估破門：車在現場、門鎖反鎖且無人見過 ➔ 通報警消里長共同評估強行入內 ➔ 平台【開案】[cite: 9]。
3. 入內處置：
• 昏倒/身體不適：緊急送醫 ➔ 平台回報 ➔ 評估機構安置 ➔ 按【解除】[cite: 9]。
• 無生命跡象：維持現場完整 ➔ 通知檢警與家屬（單身榮民由榮服處處理） ➔ 低調辦理結案 ➔ 按【解除】[cite: 9]。
