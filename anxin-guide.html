一、突發狀況處理 SOP 包含疾病不適、天然災害、失聯、送餐未取處置流程
✚
💡 核心應變原則：邊處理、邊回報
系統機制：按 開案 反紅置頂 ➔ 處理完畢按 解除
🚑 1. 疾病/身體不適
🌪️ 2. 天災/突發事件
🔍 3. 失聯協尋
🍱 4. 送餐未取/未出
🩺 1. 疾病或身體不適處置流程
1
【判斷】評估服務對象健康狀況
評估是否有生命危險或屬緊急狀況。
⬇
🚨
有生命危險 / 緊急狀況
  • 立即撥打 119 送醫及陪同就醫。
  • 於平台聊天室按下 開案（反紅置頂）。
  • 群組簡要回報狀況。
⚠️
無生命危險 / 無法判斷
  • 於平台聊天室按下 開案（反紅置頂）。
  • 群組回報現況，俾利醫師或個管師評估給予建議。
⬇
🏥
【處置】醫療處置與共同評估
優先解決健康問題。住院期間由個管師於平台通報，服務與醫療端共同評估後續處遇（返家、護理之家、榮家等）。
⬇
✓
【結案】解除警報與恢復設定
身體不適狀況處置完畢後，於「優先處理管理」按下 解除，回歸常態服務。
🌊 2. 天然災害 / 突發事件處置流程
1
【確認】自身與個案安全確認
先注意自身安全，再確認個案安全狀況。
⬇
✓
個案安全無虞
於群組回覆安全狀況並持續追蹤。
🚨
有危難風險
  • 立即通知警消救難單位。
  • 於平台按下 開案 置頂。
  • 評估風險並連結社區資源。
⬇
🏡
【安置】資源連結與緊急安置
有緊急安置必要時，於平台協調社政、榮家或長照機構協助。
⬇
✓
【結案】風險排除與解除機制
危難風險處境排除後，於平台按 解除 恢復常態。
🔍 3. 失聯協尋處置流程
1
【釐清】詢問與狀況確認
主動詢問家屬、鄰居、長照單位最後接觸時間。若僅暫時外出則群組追蹤；確認失聯則啟動協尋。
⬇
2
【啟動】開案與聯合協尋
於平台按下 開案 置頂，協請相關人員共同尋找。
⬇
3
【報案】警政報案（24小時內）
最遲 24 小時內未尋獲者向警政單位報案（有眷通知家屬，單身由榮服處辦理）。
⬇
✓
【結案】尋獲處置與解除
尋獲並確認健康（必要時送醫）➔ 平台回報 ➔ 按 解除。
🏠 4. 送餐未取 / 多時未外出處置流程
1
【確認】生活跡象現場確認
確認交通工具是否異常、門鎖狀態（外鎖/反鎖），並聯絡相關人員釐清。
⬇
2
【評估】開案與評估強行入內
車在現場、門反鎖且未見個案 ➔ 立即通報警消/里長評估強行入內 ➔ 按 開案。
⬇
🏥
昏倒 / 身體不適
緊急送醫 ➔ 平台回報 ➔ 評估安置 ➔ 按 解除。
✝
無生命跡象
維持現場完整 ➔ 通知檢警與家屬（單身由榮服處處理） ➔ 低調辦理結案。
